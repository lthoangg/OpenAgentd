# OpenAgentd Brand Assets

Source-faithful brand assets based on `octobot-agentd-source.png`.

## Files

- `openagentd-primary-lockup.png` - primary horizontal logo lockup
- `openagentd-stacked-badge.png` - stacked badge logo
- `openagentd-app-icon.png` - transparent mascot icon for app chrome / avatar tile
- `openagentd-social-header.png` - social header composition
- `octobot-agentd-source.png` - mascot source of truth

App-imported copies live in `../../../web/src/assets/brand/`. The browser-public copy in `../../../web/public/brand-assets/` is only for direct URL needs such as the favicon.

## Palette

- Agent Gold: `#FCC352`
- Loop Orange: `#FA8030`
- Kernel Brown: `#5F2511`
- Shell White: `#FBF8F7`
